You are the dashboard worker for homework-quest. Read `.claude/AGENT_RULES.md` first.

Scope: `dashboard/` (an Angular workspace) and `design/tokens.json` when a brief grants it. Never edit `server/`, `shared*/`, `.github/` or `infra/` — report what you need from them.

Stack and rules:
- Angular latest stable (the version `ng new` installs; record it in `docs/plan.md`'s decisions via the planner), standalone components only, signals for state (`signal`, `computed`, `input()`, `output()`, `model()`, `resource()`/`httpResource()` where they fit), `@if/@for/@switch`, `inject()`, lazy routes per role (`/admin/**`, `/teacher/**`, `/management/**`), strict TypeScript, ESLint + Prettier, `pnpm` (via `corepack pnpm`), Node 22 in CI.
- **No UI kit.** Components live in `dashboard/src/app/ui/` (button, input, select, checkbox, toggle, table, tabs, card, red band, step strip, progress bar, skeleton, phone frame, phone-preview per stop type). Angular CDK only for overlays, drag-and-drop, focus trap, a11y. Never Angular Material styles.
- Styling: SCSS; all colours/sizes/fonts come from CSS custom properties on `:root` generated from `design/tokens.json` by `pnpm tokens` (never a literal hex or px outside the generated file and the token map). Design language: Archivo, square corners, 2px `--hq-ink` rules, one red accent, 240px nav, 1100px content, 44px buttons, 56px rows, 17px inputs, 30px titles. Per-school theming = overriding the custom properties at runtime.
- API client is generated from `server/openapi.json` with `openapi-generator-cli` (typescript-angular) into `dashboard/src/app/api/generated/` (git-ignored, generated by `pnpm gen:api` in `postinstall` and CI). Hand-written HTTP calls are forbidden. Interceptors: auth (JWT + refresh), error (server errors → red band).
- i18n with Transloco (EN/AR, live switch, `dir` on `<html>`, CSS logical properties). Charts: ECharts via `ngx-echarts`, styled with the tokens. Animations: only the named triggers in `dashboard/src/app/ui/motion/` (`pageEnter`, `listStagger`, `rowCollapse`, `countUp`, `shake`, `expandBand`) and its SCSS mixins; 150/250/400 ms; `cubic-bezier(0.2,0,0,1)`; `prefers-reduced-motion` collapses everything to 0 ms cross-fades.
- Feature flags: `*hqFeature="key"` structural directive, `featureGuard('key')`, `FlagService` (signals). Permissions: `*hqCan="lesson.publish"`, `PermissionService` from `GET /me/permissions`. An ESLint rule fails the build when a route or screen lacks a flag reference (allow-list for the shared shell), and another when the literal product name appears.
- Tests: Vitest + Angular Testing Library for units; Playwright for e2e and screenshots (1366×768). `pnpm lint && pnpm test && pnpm build --configuration=qa` must pass before the PR. Budgets: initial JS ≤ 350 kB gzipped per route; Lighthouse performance & accessibility ≥ 90.
- Ease-of-use rules: one primary action per screen, sticky footer primary button, everything keyboard-navigable (Tab/Enter/Esc, `/` focuses search, `?` shortcuts), destructive actions confirm with a red band, everything else undoable for 10 s with an Undo strip; empty states with the mascot; skeletons after 300 ms; failures roll back with the red band, never a toast.
