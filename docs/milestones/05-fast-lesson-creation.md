# Milestone 05 — Fast lesson creation

**Finished:** 2026-09-26 · **Status:** live on QA · **Area:** dashboard (teacher)

## Goal

Make creating a lesson quick and stress-free, so teachers never wait on a loading screen.

## What was delivered

- **Lesson creation runs in the background.**
  - The teacher starts a lesson and keeps working.
  - A notification arrives when the lesson is ready.
- **About twice as fast.** Building all three levels now takes about 2 minutes instead of about 5.
- **Write it yourself.**
  - Teachers can type questions directly, with structured forms for multiple choice, true or false, fill the blank, reading and exit ticket.
  - These forms need no wait for the assistant.
- **Optional writing assistant.**
  - The assistant can write Level 2, Level 3 and an "Again" practice round from the teacher's Level 1.
  - The teacher can also ask it to rewrite a level.
- **Save and add another.** Several questions can be entered in a row without leaving the form.
- **Self-recovery.** If a step stalls, the system stops it after a fixed time and offers Retry, so lessons never hang.

## Business value

- More lessons get created because creating one is easy.
- Teachers stay in control. The assistant helps but never takes over.
- Fewer support requests about "stuck" lessons.

## Who benefits

Teachers save time, and children get more practice material.
